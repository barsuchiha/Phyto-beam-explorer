# Свет для растений

Интерактивная схема для сравнения геометрии светильников: высоты, угла пучка, наклона и яркости. Показывает расчётные PPFD, суточную дозу DLI и цветовую карту для десяти комнатных растений.

[Открыть калькулятор](https://barsuchiha.github.io/Phyto-beam-explorer/)

Выберите растение и источник, задайте общий поток PPF и часы работы лампы, затем меняйте положение и угол пучка. Настройки сохраняются в этом браузере. Регистрация и серверная часть не нужны.

Цветовая оценка — ориентир для сравнения сценариев. «Оптимально» обозначает рабочую цель, а «опасно» — условный сигнал риска, не установленный порог ожога. PPF задаётся вручную; это не паспортный расчёт конкретной лампы. Подробности — в [допущениях модели](METHOD.md).

## Файлы и запуск

- `index.html` — самостоятельная страница с интерфейсом и расчётом.
- `METHOD.md` — формулы, допущения и источники.
- `.nojekyll` — публикация готовой страницы без обработки Jekyll.

Для локального просмотра откройте `index.html` в браузере или выполните `python3 -m http.server 8765` в этой папке и откройте `http://localhost:8765`.

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. Обновления `index.html` в `main` публикуются автоматически.
