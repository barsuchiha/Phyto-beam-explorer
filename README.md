# Свет для растений

Интерактивная схема света для десяти комнатных растений. Размер растения меняется ползунком; лампа перемещается сверху вбок на 0–90°, а экраны закрывают выбранный сектор вокруг неё. Показывает расчётные PPFD/DLI на условной объёмной кроне и распределение полного потока. Поглощающий, зеркальный и матовый экраны сравниваются при одинаковой геометрии и мощности; коэффициент отражения регулируется.

[Открыть калькулятор](https://barsuchiha.github.io/Phyto-beam-explorer/)

[Новая геометрия растения и экраны](CROWN_MODEL.md): размеры по видам, управление, формулы, баланс потока и ограничения. Стол удалён. Среднее по объёмной оболочке отличается от прежней горизонтальной карты; цвета остаются условными ориентирами.

[Отражающие экраны](REFLECTION_MODEL.md): направленное и рассеянное отражение, повторные попадания, потери на экране и платах, дополнительный PPFD на кроне. Отражение 90% по умолчанию — допущение, не паспорт материала. Отражатель может увеличить и полезный свет, и поток в комнату по сравнению с поглощающим экраном. Таблица показывает оба эффекта; названия поверхностей переключают карту.

Раскрытие стенок меняется ползунком 0–120°: от цилиндра до расходящегося конического сектора. Длина стенки сохраняется; её наклон меняет отражённый PPFD и распределение потока. Отдельно регулируются сектор вокруг лампы и поворот. Это модель формы, не проверка механики гибкого купола.

[Проверка всех 21 профиля для домашней досветки](HOME_REVIEW.md): девять конкретных изделий, двенадцать условных компоновок, сравнение света и ограничения выбора. Проверено 12.11.2026.

Выберите растение, плату, количество и драйвер. У трёх плат Samsung PPF рассчитывается по току и диммированию; пучок фиксирован по диаграмме LM301B. В режиме LDD можно отдельно менять яркость двух групп. Для прежних условных компоновок PPF и угол задаются вручную. Настройки сохраняются в этом браузере. Регистрация и серверная часть не нужны.

MiniFermer 1.9.3 (3500 K) и 1.9.4 (4000 K) находятся в группе «оценка с допущениями». Для них показаны диапазоны среднего и центрального PPFD и DLI по девяти сценариям. Таблица под результатами разделяет данные продавца и принятые параметры диодов, спектра, нагрева, пучка и диммирования. Карта и проценты площади показывают базовый сценарий; оценка растения учитывает весь диапазон. Конкретные драйверы для этих плат пока не проверены. Этот диапазон не является измеренной погрешностью или доверительным интервалом.

Цветовая оценка — ориентир для сравнения сценариев. «Оптимально» обозначает рабочую цель, а «опасно» — условный сигнал риска, не установленный порог ожога. Диаграмма отдельного LED и таблица PPF платы уменьшают число допущений, но не заменяют измерения светильника с куполом. Подробности — в [методике](METHOD.md) и [подборе модулей и драйверов](MODULES.md).

MiniFermer 3.6 добавлен как **гипотеза Seoul SunLike E1 + Osram GH CSSRM3.24 660 нм**. Белые и красный считаются отдельно: 24 + 1 LED, PPF одной платы при 100% ≈22,6–27,2 мкмоль/с, база ≈25,05. Три сценария раскрывают принятые токи, температуру и поправки по графикам; Seoul не подтверждён как фактический белый LED. Отдельная таблица сравнивает центральный PPFD одной платы при 100% с четырьмя замерами MiniFermer на 20–50 см. База ниже них на 26–37%; источник не подогнан под замеры, условия которых описаны не полностью. Сравнение остаётся фиксированным при движении ползунков.

ЭРА добавлены отдельной группой: **GREEN LINE 18 Вт — PPF 36 + IES изготовителя**, **E27 18/25 Вт — PPF 36/45 и диапазон по предполагаемым пучкам 110°/120°/130°**. У GREEN LINE явно отмечено приближение ближнего поля; у E27 — условная геометрия и неизвестная реальная диаграмма. Все три работают в модели при 100%: штатного DIM нет. Число светильников, высота, наклон и фотопериод регулируются. Исходники и допущения видны в раскрывающемся блоке ЭРА.

## Структура проекта

Обычная статическая страница с ES-модулями. Сборщик, серверная часть, iframe и экспорт из фрагмента больше не нужны. `index.html` — единственный источник разметки; браузер загружает те же расчётные модули, которые проверяют тесты.

| Файлы                                                                            | За что отвечают                                                                              |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `index.html`                                                                     | Разметка, подписи, варианты в списках                                                        |
| `styles/`                                                                        | Общие стили, элементы управления, схемы и адаптивная раскладка                               |
| `src/data/`                                                                      | Профили источников, паспортные таблицы плат и драйверов, растения                            |
| `src/models/photometry.js`                                                       | Диаграмма излучения, конечный размер источников, PPFD на плоскости                           |
| `src/models/crown.js`, `crown-scenario.js`, `src/data/plant-shapes.js`           | Объёмная крона, поворот сборки, экраны, PPFD и баланс полного потока                         |
| `src/models/reflections.js`, `screen-geometry.js`, `src/ui/screen-comparison.js` | Повторные зеркальные/матовые отражения, карта отражённого PPFD и сравнение трёх поверхностей |
| `src/models/hardware.js`                                                         | Рабочая точка, совместимость драйверов, ток и PWM                                            |
| `src/models/minifermer.js`, `mini36.js`                                          | Допущения и диапазоны MiniFermer; фиксированное сравнение 3.6 с продавцом                    |
| `src/models/ies.js`, `era.js`                                                    | Импорт и нормировка IES, три профиля ЭРА и сценарии E27                                      |
| `data/era/`, `scripts/import-era-ies.mjs`                                        | Архив исходного IES и воспроизводимый перенос в JS: `node scripts/import-era-ies.mjs`        |
| `src/models/layout.js`, `plants.js`                                              | Размещение плат, DLI и оценка растений                                                       |
| `src/calculate.js`                                                               | Единый расчёт сценария и кэш оптики без доступа к DOM                                        |
| `src/state.js`                                                                   | Начальные значения, проверка настроек, сохранение и чтение старых версий                     |
| `src/ui/`                                                                        | Ползунки, пояснения, результаты, SVG-схемы и подсказки                                       |
| `src/app.js`                                                                     | Запуск страницы и связь событий с расчётом и отображением                                    |
| `tests/`                                                                         | Проверки моделей, сценариев и сохранения настроек                                            |
| `METHOD.md`, `MODULES.md`                                                        | Методика, источники, подбор плат и драйверов                                                 |

Поток данных: **событие ползунка → состояние → расчёт сценария → отображение**. Модели не зависят от HTML или браузера. Формулы, исходные данные и оптические допущения при разделении не менялись.

## Локальный запуск

В папке проекта выполните:

```sh
python3 -m http.server 8765
```

Откройте [localhost:8765](http://localhost:8765). Нужен HTTP-сервер: при открытии через `file://` браузер может блокировать ES-модули. Устанавливать npm-пакеты для работы страницы не нужно.

## Проверки

При установленном Node.js:

```sh
npm test
```

Тесты напрямую импортируют рабочие модули. `tests/fixtures/baseline.json` содержит результаты 29 сценариев из опубликованной версии до разделения (коммит `32365c83bcb8fd3381b767b3a80e40b21dcbacf0`): все 18 источников, крайние настройки и несовместимые драйверы. При намеренном изменении модели обновлять эти значения следует после проверки методики, а не просто ради прохождения теста.

При рефакторинге также сверены полные карты PPFD и диапазоны с прежним HTML, проверены переключения источников, нулевая яркость, перезагрузка с сохранением настроек и узкий экран. Ключ localStorage и формат прежней оболочки сохранены; читаются схемы `phyto-beams-v1`–`v9`. Новые проверки отражения включают баланс фотонов, предельные коэффициенты отражения, возврат на платы, сходимость и диапазоны PPFD. Всего проходят 34 теста, включая наклон стенок и сходимость открытого отражателя.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Публикуется весь набор `index.html`, `src/`, `styles/`, `data/` и `.nojekyll`. Сборка и повторный экспорт не нужны; все пути относительные и работают в `/Phyto-beam-explorer/`. Изменение только одного HTML больше не переносит изменения расчёта — нужно коммитить изменённые JS/CSS-файлы вместе с ним.

Чтобы добавить источник: внесите профиль и размеры в `src/data/profiles.js`, паспортные данные или модель допущений — в соответствующий файл `src/data/` или `src/models/`; подключите выбор модели в `src/calculate.js` и раскладку в `src/models/layout.js`. Добавьте вариант в список `index.html`, пояснения в `src/ui/details.js` и проверки расчёта. Обоснование исходных чисел остаётся в `METHOD.md` и `MODULES.md`.
