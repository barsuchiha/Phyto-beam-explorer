# Свет за день: простой индикатор

В 3D-примерочной осталась одна цветная карта — PPFD с общей шкалой 0–300+. Цветовые карты DLI удалены; старые сохранённые настройки переводятся в PPFD. Под сценой по умолчанию показано общее солнце для всей листвы. Нажатие на лист добавляет отдельное маленькое солнце, не меняя общее. Полные числа и баланс находятся в раскрываемом блоке.

## Что сравнивается

Для каждого целого листа выбирается более освещённая сторона по базовому сценарию. Эта же физическая сторона используется во всех сценариях источника. По умолчанию отдельный лист не выбран. Можно нажать на лист в 3D либо раскрыть список; «Закрыть» убирает локальную оценку и выделение.

`DLI = DLI лампы + DLI окна` на одной физической стороне листа. Для лампы: `PPFD × часы работы × 0,0036`. Для окна: средний рассеянный PPFD × длительность дня + средний прямой PPFD × часы прямого солнца, всё умноженное на 0,0036. Часы лампы не масштабируют свет окна. Совпадение периодов не меняет сумму фотонов; непрерывность темноты и фотопериод отдельно не моделируются.

Общее солнце — условный индикатор досветки по площади листвы:

`Σ(площадь листа × min(DLI его выбранной стороны / L, 1)) / Σ(площадь листа)`.

Здесь `L` — нижний ориентир. Весом является площадь одной стороны, а не число листьев. Вклад каждого листа ограничивается до усреднения: избыток на маленьком ярком листе не компенсирует большую затенённую площадь. Например, листва площадью 10% с DLI 60 и оставшиеся 90% с DLI 0 при L=6 дают обычное среднее DLI 6, но общее солнце заполнено только на 10%.

Отдельно показана доля площади листьев, средний DLI выбранной стороны которых достиг нижней границы. Листья выше верхней границы входят в достигшие нижней, но их доля дополнительно подписывается как превышение. Не утверждается, что каждый участок такого листа освещён одинаково. Полное солнце означает достижение нижнего ориентира всеми листами модели; оно не гарантирует нормальный рост живого растения.

Все общие величины сначала вычисляются для каждого согласованного сценария источника, затем из них берётся диапазон. Минимумы разных листьев не смешиваются в искусственный сценарий. `sides[].values` сохраняет уже рассчитанные PPFD каждого сценария; перенос света не менялся. Общее солнце и его доли не зависят от выбранного для просмотра листа.

Сравнение использует существующие условные группы растения: DLI 3–6, 6–10 или 12–16 моль/(м²·сутки). Это проектные ориентиры, не измеренные потребности конкретного экземпляра. Свет окна входит при выборе погодного сценария; это условные уровни, не измерение квартиры. Верхняя граница не является порогом ожога.

## Значок и подпись

- Вся листва ниже нижней границы: «Света пока мало».
- Есть листва ниже, остальные в интервале: «Части листвы света мало».
- Есть одновременно листва ниже и выше интервала: «Есть яркие и затенённые листья».
- Вся листва внутри интервала: «По ориентиру света хватает».
- Вся листва достигла нижней границы, часть выше верхней: «Есть листья выше ориентира».
- Сценарии дают разные общие оценки: «Результат на границе».
- Оба источника выключены: «Источники света выключены».

Общее солнце заполняется линейно по указанному индикатору (0–100%); значение не является процентом потребности в росте или поглощённых фотонов. Локальное солнце заполняется как `min(DLI / L, 1)`; его численная доля может превышать 100%. Оба значка показывают базовый сценарий, рядом при необходимости указан диапазон. Превышение верхней границы обозначается словами, а не новой цветной картой.

При малом числе попаданий на сторону есть пояснение о неточности слабого света. Ноль попаданий не доказывает абсолютной темноты. В режиме оболочки оценка по листу недоступна; предложен явный переход к расчёту на листьях.

Расчёт лампы и ориентиры сохранены; окно рассчитано отдельно. Выбор другого листа обновляет только локальный индикатор без повторной трассировки. Полные PPFD/DLI обеих сторон доступны в «Цифры и баланс света».

## Окно: модель и допущения

Окно находится на задней стене Y = 1,15 м; X от −0,4 до 1 м, Z от 0,7 до 2,3 м. Рама и подоконник иллюстративны. Геометрия окна фиксирована и не является обмером комнаты пользователя.

| Параметр | Принято при 100% яркости | Статус |
| --- | --- | --- |
| Пасмурно: средний рассеянный PPFD | 80 мкмоль/(м²·с) на вертикальной плоскости в 0,5 м от центра окна, нормаль к окну | Проектный сценарий |
| Солнечно: средний рассеянный PPFD | 200 на той же плоскости | Проектный сценарий |
| Солнечно: средний прямой PPFD | 600 на плоскости, перпендикулярной лучу | Проектный сценарий |
| Длительность дня / прямого солнца | 10 ч / 3 ч, доступны 4–16 ч / 0–8 ч; прямое не длиннее дня | Регулируемые допущения |
| Яркость окна | 0–200% сценария | Регулируемое допущение |
| Неопределённость яркости | 0,6 / 1 / 1,4 от сценария для всех листьев одновременно | Сценарии чувствительности, не доверительный интервал |
| Положение солнца | Азимут −15°/0°/15°, высота 25°/35°/25°, равные доли прямого времени | Три условных направления, без даты/географии |

Оба уровня PPFD заданы **после стекла**; дополнительный коэффициент пропускания не применяется. Используется средний уровень за указанный период, а не полуденный максимум на все часы. Значения 80/200/600 не взяты из замеров и не выданы за паспорт окна.

`window-light.js` интегрирует равномерную радиансную апертуру: `L × cos(приёмник) × cos(окно) × dA / r²`. Нормировка — по указанному вертикальному датчику. Для каждого участка листа берутся 8 распределённых по площади точек и 6 × 6 точек окна. Прямой свет учитывает пересечение луча с апертурой и косинус наклона листа. BVH проверяет затенение другими листьями; корпус, платы и экраны считаются непрозрачными, мебель — преградой. Вторичные отражения и пропускание листвой/прозрачными деталями светильника не рассчитаны. Рамы, горшки и стебли не затеняют расчёт. В тени результат может быть занижен без комнатных отражений.

Коэффициенты считаются один раз для геометрии; погода, яркость и часы меняют DLI сразу. При изменении геометрии пересчитываются и окно, и лампа. Включение окна из режима оболочки переводит расчёт на листья. Старые сохранения получают «Без окна», чтобы прежняя оценка не изменилась без выбора пользователя.

Полная доза сначала складывается на каждой стороне. Выбирается одна физическая сторона по номинальной сумме, затем она сохраняется во всех сценариях. Нельзя складывать максимум лампы на лицевой стороне с максимумом окна на обратной. Все сочетания сценариев лампы и общей яркости окна сохраняются согласованными по всей листве. Проценты «окно / лампа» — доли среднего DLI выбранных сторон, а не доли заполнения общего солнца. Карта PPFD, траектории, баланс и датчик сверху остаются диагностикой **лампы**, это подписано рядом с переключателем видов.

Определение DLI и необходимость интегрировать меняющийся дневной свет: [Apogee Instruments](https://www.apogeeinstruments.com/daily-light-integral-measurement/). Для уточнения конкретного окна нужен ряд замеров PPFD за день у растения с указанием положения/ориентации датчика, окна, сезона и погоды. Источник подтверждает метод интегрирования, а не численные уровни наших сценариев.
