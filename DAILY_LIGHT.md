# Свет за день: простой индикатор

В 3D-примерочной осталась одна цветная карта — PPFD с общей шкалой 0–300+. Цветовые карты DLI удалены; старые сохранённые настройки переводятся в PPFD. Под сценой по умолчанию показано общее солнце для всей листвы. Нажатие на лист добавляет отдельное маленькое солнце, не меняя общее. Полные числа и баланс находятся в раскрываемом блоке.

## Что сравнивается

Для каждого целого листа выбирается более освещённая сторона по базовому сценарию. Эта же физическая сторона используется во всех сценариях источника. По умолчанию отдельный лист не выбран. Можно нажать на лист в 3D либо раскрыть список; «Закрыть» убирает локальную оценку и выделение.

`DLI = средний PPFD этой стороны × часы × 0,0036`.

Общее солнце — условный индикатор досветки по площади листвы:

`Σ(площадь листа × min(DLI его выбранной стороны / L, 1)) / Σ(площадь листа)`.

Здесь `L` — нижний ориентир. Весом является площадь одной стороны, а не число листьев. Вклад каждого листа ограничивается до усреднения: избыток на маленьком ярком листе не компенсирует большую затенённую площадь. Например, листва площадью 10% с DLI 60 и оставшиеся 90% с DLI 0 при L=6 дают обычное среднее DLI 6, но общее солнце заполнено только на 10%.

Отдельно показана доля площади листьев, средний DLI выбранной стороны которых достиг нижней границы. Листья выше верхней границы входят в достигшие нижней, но их доля дополнительно подписывается как превышение. Не утверждается, что каждый участок такого листа освещён одинаково. Полное солнце означает достижение нижнего ориентира всеми листами модели; оно не гарантирует нормальный рост живого растения.

Все общие величины сначала вычисляются для каждого согласованного сценария источника, затем из них берётся диапазон. Минимумы разных листьев не смешиваются в искусственный сценарий. `sides[].values` сохраняет уже рассчитанные PPFD каждого сценария; перенос света не менялся. Общее солнце и его доли не зависят от выбранного для просмотра листа.

Сравнение использует существующие условные группы растения: DLI 3–6, 6–10 или 12–16 моль/(м²·сутки). Это проектные ориентиры, не измеренные потребности конкретного экземпляра. Свет окна неизвестен и не входит в оценку. Верхняя граница не является порогом ожога.

## Значок и подпись

- Вся листва ниже нижней границы: «Лампы пока мало».
- Есть листва ниже, остальные в интервале: «Части листвы света мало».
- Есть одновременно листва ниже и выше интервала: «Есть яркие и затенённые листья».
- Вся листва внутри интервала: «По ориентиру света хватает».
- Вся листва достигла нижней границы, часть выше верхней: «Есть листья выше ориентира».
- Сценарии дают разные общие оценки: «Результат на границе».
- Нет исходного PPF: «Лампа выключена».

Общее солнце заполняется линейно по указанному индикатору (0–100%); значение не является процентом потребности в росте или поглощённых фотонов. Локальное солнце заполняется как `min(DLI / L, 1)`; его численная доля может превышать 100%. Оба значка показывают базовый сценарий, рядом при необходимости указан диапазон. Превышение верхней границы обозначается словами, а не новой цветной картой.

При малом числе попаданий на сторону есть пояснение о неточности слабого света. Ноль попаданий не доказывает абсолютной темноты. В режиме оболочки оценка по листу недоступна; предложен явный переход к расчёту на листьях.

Расчёт переноса света, PPF, геометрия и ориентиры не изменены. Выбор другого листа обновляет только локальный индикатор без повторной трассировки. Полные PPFD/DLI обеих сторон доступны в «Цифры и баланс света».
